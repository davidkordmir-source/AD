# Fast Sector Viewshed 3.0

Primary output: visible.shp (visible cells only). visibility.shp contains all classes; sectors.shp contains analysis bounds.

Read README_FAST_FA.md for installation, update and large-grid settings.

Install Miniforge if needed, then run Install_Fast_Viewshed.bat once and Run_Fast_Viewshed.bat to open the GUI.

This is a Python/Qt source GUI package. Windows installation is not yet verified on Windows. Numerical equivalence to Global Mapper on the user DEM is not established.
