# به‌روزرسانی کوچک به ۳٫۶٫۲ — ظاهر تازه و لایسنس

بستهٔ بزرگ قبلی ۳٫۵ یا ۳٫۶٫۰ را دوباره دانلود نکنید؛ کلید License_OwnerData را حفظ کنید.
محتویات این ZIP را کنار `Build_Custom_Setup.bat` و `Payload` قبلی استخراج کنید.
`Apply_3_6_Update.bat` را اجرا کنید و تا پیام `Update applied (3.6.2)` صبر کنید.
سپس `Build_Custom_Setup.bat` را اجرا کنید تا خروجی جدید با لوگوی قبلی شما ساخته شود.

نام کشورها روی نقشه نمایش داده می‌شود؛ ظاهر سرمه‌ای/فیروزه‌ای و نقاط قرمز اضافه
شده‌اند. خروجی جدید بدون لایسنس مخصوص دستگاه باز نمی‌شود. ابتدا
`LICENSE_GUIDE_FA.md` را بخوانید. فقط Output و لایسنس صادرشده را به افراد بدهید؛
ابزار صدور و `License_OwnerData` نزد خودتان بماند. مدت از اولین فعال‌سازی روی دستگاه گیرنده حساب می‌شود.

لوگو و خروجی قبلی حفظ می‌شوند. نسخه‌های قدیمی نصب‌شده خودکار لایسنس‌دار نمی‌شوند؛
دریافت‌کنندگان باید نصب‌کننده یا پوشهٔ Portable جدید را دریافت کنند.
