# Fast Viewshed 3.4.0 — نصب‌کنندهٔ آفلاین ویندوز

[**دانلود بستهٔ نصب ویندوز (حاوی Setup.exe)**](https://github.com/davidkordmir-source/AD/releases/download/v3.4.0-installer/00_FastViewshed_Windows_Setup_v3.4.0.zip)

ZIP را **Extract All** کنید و **Setup.exe** را اجرا کنید. **Next → Install → Finish** را بزنید و گزینهٔ **Create a desktop shortcut** را روشن نگه دارید تا آیکون هواپیما روی دسکتاپ ایجاد شود.

[دانلود مستقیم نصب‌کنندهٔ EXE](https://github.com/davidkordmir-source/AD/releases/download/v3.4.0-installer/FastViewshed_Setup_v3.4.0_Windows_x64.exe)

- نقشهٔ پیش‌فرض با **area و point ارسالی شما** جایگزین شده است: ۲۵۵ محدوده و ۴۲۵۵ نقطه، WGS 84.
- در پیش‌نمایش **انتخاب نقشهٔ خودم…** برای SHP، GeoJSON، GPKG، KML یا GeoTIFF؛ نگهداری نسخهٔ محلی و بازیابی در اجرای بعد. فایل بدون CRS نیازمند EPSG صحیح است.
- **شخصی‌سازی رابط 🔒** با رمز مدیر: عنوان، اندازهٔ فونت، رنگ‌ها، بارگذاری لوگوی اختصاصی و تغییر رمز. رمز در متن راهنما منتشر نشده است.
- نمایش لوگو هنگام شروع؛ پیش‌فرض هواپیما است و لوگوی دلخواه از تنظیمات قابل انتخاب است.
- نقشهٔ برداری بدون ساده‌سازی؛ پس‌زمینه در تحلیل GDAL دخالت ندارد. نمایش جهان در Web Mercator به حدود قطبی این تصویر محدود است.

پایتون، GDAL، Qt و نقشه داخل بسته هستند. نصب و اجرا دانلودی ندارند. ارتفاع از ستون تکست، نام‌گذاری خروجی، شیپ مشترک/مستقل، رد رکورد خراب و گزارش‌های قبلی حفظ شده‌اند.

گزارش نصب واقعی، ساخت میان‌بر دسکتاپ، بازشدن GUI و حذف برنامه در WINDOWS_INSTALLER_VALIDATION.json و گزارش GIS با اینترنت مسدود در WINDOWS_OFFLINE_VALIDATION.json همراه انتشار است. SHA256SUMS.txt برای بررسی صحت فایل‌هاست.
